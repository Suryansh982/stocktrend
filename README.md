# stocktrend
Deployment - Streamlit

To predict trends, we utilize an LSTM (Long Short-Term Memory) model, a highly effective approach for sequence prediction tasks. LSTMs are particularly powerful because they can retain crucial past information while discarding irrelevant data. This ability makes them well-suited for trend forecasting.

The model performed well, demonstrating its effectiveness in sequence prediction problems.
